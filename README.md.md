# pingzong-money-skill

**价值优先消费决策系统 · 严格量化版**

> 一套用分数说话的理性消费决策框架。  
> 帮助你在花钱之前，用明确规则判断「这钱该不该花」。

## 核心理念

- 钱真正的作用是购买**持续的生活质量**，而不是购买别人眼里的体面。
- 最好的支出，往往是别人看不到、但你每天都能感受到的（睡眠、健康、时间、平静、能力）。
- 每一笔消费，本质都是在用「未来的选择权」交换「现在的东西」。

因此，判断一笔钱该不该花，核心不是「贵不贵」，而是：

**它是否在增加你的长期选择权、健康、时间或关系质量？**

---

## 评分体系（满分 100 分）

| 维度                   | 权重  | 满分 | 评分标准（严格定义） |
|------------------------|-------|------|----------------------|
| 1. 使用频率            | 20%   | 20分 | 5 = 几乎每天使用<br>4 = 每周 ≥4 次<br>3 = 每周 1-3 次<br>2 = 每月几次<br>1 = 一年几次或更少 |
| 2. 价值持续时间        | 15%   | 15分 | 5 = 价值可维持 ≥2 年<br>4 = 1-2 年<br>3 = 6-12 个月<br>2 = 1-6 个月<br>1 = 不到 1 个月就明显衰减 |
| 3. 真实生活质量提升    | 20%   | 20分 | 5 = 对睡眠/身体/精力/情绪有显著且持续改善<br>4 = 明显改善<br>3 = 一定改善<br>2 = 轻微改善<br>1 = 几乎无实际改善 |
| 4. 时间或精力回报      | 15%   | 15分 | 5 = 每月可稳定节省 ≥10 小时或大幅降低消耗<br>4 = 每月节省 5-10 小时<br>3 = 每月节省 2-5 小时<br>2 = 节省很少<br>1 = 几乎不节省 |
| 5. 能力或健康增值      | 10%   | 10分 | 5 = 明显提升长期技能或健康水平<br>4 = 较明显提升<br>3 = 一定提升<br>2 = 提升微弱<br>1 = 无提升 |
| 6. 不可替代性          | 10%   | 10分 | 5 = 几乎没有更优或更便宜的替代方案<br>4 = 替代方案明显更差<br>3 = 有可接受替代<br>2 = 有较好替代<br>1 = 有明显更好/更便宜的替代 |
| 7. 财务安全影响        | 10%   | 10分 | 5 = 完全不影响应急金和长期目标<br>4 = 影响极小<br>3 = 有轻微影响但仍可接受<br>2 = 会明显压缩安全垫或目标<br>1 = 会动用应急金或严重干扰长期目标 |

**计算方式**：每个维度得分 = 等级分 × 对应权重满分，然后七项相加得到总分（满分 100 分）。

---

## 决策规则（严格阈值）

| 总分区间     | 决策结果               | 说明 |
|--------------|------------------------|------|
| ≥ 80 分      | **强烈建议购买**       | 可立即执行 |
| 65 – 79 分   | **建议购买**           | 建议再对比 1-2 个替代方案后购买 |
| 50 – 64 分   | **谨慎购买 / 延后**    | 强制冷静期：小额 24h，中额 48h，大额 72h |
| 35 – 49 分   | **不建议购买**         | 除非有特殊刚需，否则拒绝 |
| < 35 分      | **明确拒绝**           | 直接否决 |

### 金额分级附加规则

- **小额**（≤ 月收入的 3%）：按上面分数决策即可
- **中额**（月收入的 3% - 10%）：总分需 ≥ 65 分才建议购买
- **大额**（> 月收入的 10%）：总分需 ≥ 75 分，**且财务安全影响必须 ≥ 4 分**，否则直接拒绝

---

## 一票否决条款

出现以下任一情况，**直接判定为不建议购买或明确拒绝**，不再进行评分：

1. 主要购买动机是情绪（生气、焦虑、无聊、攀比、奖励自己）
2. 主要价值是「让别人看到」或「显得有面子」
3. 会动用应急金（3-6 个月生活费）
4. 购买后会导致下个月必要生活支出出现缺口
